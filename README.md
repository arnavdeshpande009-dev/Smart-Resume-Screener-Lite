# Smart Resume Screener Lite

AI-powered resume screening system built using React, Python, and NLP techniques.

## Features

- Resume and job description matching
- Keyword-based scoring system
- NLP preprocessing pipeline
- Lightweight and fast UI
- Recruiter-style filtering approach

## Tech Stack

### Frontend
- React
- Vite
- HTML/CSS

### Backend
- Python
- Flask

### AI/NLP
- Scikit-learn
- NLP preprocessing
- Keyword extraction

## Project Overview

Smart Resume Screener Lite was developed as a solo project during the DPGU 12-Hour Hackathon.

The system analyzes resumes against job descriptions and generates relevance-based screening results using NLP and keyword matching techniques.
